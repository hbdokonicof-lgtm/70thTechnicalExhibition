스크린 화면 설정 (9:16)

제목/부제목/메시지 목록 박스의 위치와 크기는 화면(1080×1920 캔버스) 기준 %값입니다 (0~100). 글자 크기, 배경 전환 주기, 스크롤 속도 등은 그대로 px/초 단위입니다.

레이아웃 방식: "스티커 메모형" 고정 — 메시지 목록 박스 안에 설정한 크기의 스티커 메모들이 랜덤 위치에 화면 가득 배치됩니다. 방명록이 들어온 순서대로 빈 자리부터 채워지고, 더 이상 빈 자리가 없으면 전체 메시지 중에서 랜덤으로 골라 계속 새로 나타났다 사라지기를 반복합니다 (페이드인 → 유지 → 페이드아웃).
